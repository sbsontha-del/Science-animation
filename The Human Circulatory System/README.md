# Human Respiratory & Circulatory Systems (Primary 5 Science)

An interactive, web-based educational application designed for Primary 5 Science (Activities 4.4 – 4.7), fully aligned with the Singapore Science Curriculum and official textbook guidelines.

## 🌟 Key Features

### 1. Activity 4.4 – Interactive Circulation Diagram & Simulation
- **3-Panel Layout**: Visual panels for `LUNGS`, `HEART`, and `OTHER PARTS OF THE BODY`.
- **Animated Blood Flow**: Hardware-accelerated red (oxygenated) and dashed blue (deoxygenated) animated blood drop particles flowing along smooth curves.
- **Interactive Drag & Drop**: Place organ and vessel labels correctly into the circulation diagram.

### 2. Activity 4.5 – Plant & Human Transport Systems Comparison
- **Plant Transport System**: Realistic plant model (leaves, stem, roots in soil) with continuous SVG animated water droplets (`💧`) in water-carrying tubes and food particles (`🍃`) in food-carrying tubes.
- **Human Circulatory System**: Anatomical silhouette with 4-chamber heart pulse animation, lungs, pulmonary circuit, systemic circuit, and animated blood flow (`🔴 O₂`, `🔵 CO₂`).
- **Socratic Guidance**: Interactive comparisons highlighting similarities and differences.

### 3. Activity 4.6 – Dynamic Pulse & Virtual Exercise Lab
- **Dynamic Speed Acceleration**: Heartbeat and breathing animation speeds accelerate dynamically based on exercise intensity:
  - 🛋️ **Sitting (Resting)**: 72 BPM / 16 breaths/min
  - 🚶 **Marching on Spot**: 96 BPM / 24 breaths/min
  - 🏃 **Doing 15 Jumps**: 132 BPM / 36 breaths/min
- **15-Second Interactive Timer**: Real-time counter measuring beats and breaths with automated scientific summary banners.

### 4. Activity 4.7 – Interactive Comic Flipbook Creator
- **Primary 5 Animal Avatars**: Choose your hero character – 🦊 **Pip the Fox**, 🐬 **Flipper the Dolphin**, 🦉 **Ollie the Owl**, or 🦘 **Joey the Kangaroo**.
- **Choice Locking**: Selected animal avatar locks into a clean hero header banner.
- **5-Page Circulation Story**: Flip through 5 key stages of blood circulation starting from the heart engine room.
- **Dual Writing Modes**: Switch between preset guided prompts and free-text dialogue.
- **Substance Stickers**: Clickable `🔴 Oxygen`, `🍞 Digested Food`, `🔵 Carbon Dioxide`, and `💨 Waste` badges.
- **Full Storybook Reader**: View completed comic panels in a full-screen storybook modal.

### 5. Socratic Inquiry & Real-Time Keyword Tracking
- **Scaffolded Learning**: Guided prompts and sentence starters without spoiling answer key text upfront.
- **Real-Time Keyword Badges**: Target keyword pills glow green (`✨ ✓ keyword`) dynamically as students type matching terms.
- **Page 31 Rubric**: Integrated self-assessment rubric (Just started / Getting there / Got it!).

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open terminal in the project directory:
   ```bash
   python3 -m http.server 8085
   ```
3. Open your browser and navigate to `http://localhost:8085`.
