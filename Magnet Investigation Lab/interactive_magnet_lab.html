⚖️ Fair Testing Explorer

In a fair test, change only ONE variable at a time (independent variable) while keeping all other variables constant (controlled variables).

✓ Fair Test Example:

Testing pole strength of Magnet A: Use the SAME iron nail material, SAME facing distance, and change ONLY the facing pole (N vs S).

❌ Unfair Test Example (Workbook Page 144):

Comparing a steel nail facing N pole vs an iron nail facing S pole. Two variables changed (nail material AND facing pole), making it UNFAIR!
